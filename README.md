## 💻 Local Setup & Development

```bash
# 1. Clone repository
git clone https://github.com/Sathish120804/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

```bash
# 4. Build for production
npm run build

# 5. Preview production build
npm run preview
```

## ☁️ Vercel Deployment Guide

1. Push your code to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: redesigned editorial portfolio"
   git push origin main
   ```
2. Log into [Vercel](https://vercel.com/) and click **"Add New..." > "Project"**.
3. Select your repository.
4. Verify build settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Click **Deploy**. Vercel will build and assign your production domain.
